# Scientific Visualization

Use `visualization_property_chart` for a small set of comparable numeric values. Use `visualization_sequence_track` to inspect residue-level hydropathy.

Keep units and transformations explicit. Visualization artifacts contain data and rendering intent only; they do not contain executable HTML or scripts.
